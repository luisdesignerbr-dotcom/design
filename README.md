# Luis Henrique Souza — Portfolio

A responsive, static portfolio built with HTML, CSS and vanilla JavaScript. No build step, package installation or framework required.

## Preview locally
Open `index.html` in a browser. Images currently load from the public Framer CDN, and fonts load from Google Fonts.

## Publish on GitHub Pages
1. Create a new repository on GitHub (for example `luis-portfolio`).
2. Upload **all files and folders** from this project to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub to publish the site. The URL will appear in the Pages section.

## Before publishing
- Replace the example Behance links in `index.html` with links to the individual project case studies.
- The project images use the public image URLs from the current portfolio. For a fully independent copy, download images you own into an `assets/` folder and update the image paths.
- Add your real CV PDF to the repository and link it from the page if you want a CV download.
- Verify job dates, project names and descriptions before publishing.

## Files
- `index.html` — content and page structure
- `styles.css` — responsive design and visual styling
- `script.js` — mobile navigation, reveal effects and current year

## Notes
This is a clean static recreation inspired by the publicly visible content and project imagery of the original portfolio, not an exported Framer project. Framer-specific CMS, forms and editor features are not included.
